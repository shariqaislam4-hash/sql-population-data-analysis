# SQL Population Data Analysis

## Overview

This project demonstrates practical SQL skills through the analysis of population data.

The analysis uses SQL queries to explore structured data, identify patterns, and produce evidence-based observations.

## Skills Demonstrated

- Filtering records
- Sorting data
- Grouping and aggregation
- Joining related tables
- Interpreting patterns in datasets

## Tools

- SQL
- Relational data analysis

## Project Context

This project builds on SQL data analysis skills developed through my Biological Sciences degree at Queen Mary University of London.

The focus is on using structured queries to investigate population data and translate the results into clear findings.
